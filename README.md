## 📖 About The Project

Learning QNX (Real-Time Operating System) can be challenging, especially when transitioning from beginner-friendly ecosystems like Arduino. In Arduino, interfacing with hardware is as simple as including `<Servo.h>`. 

This repository aims to bring that same plug-and-play simplicity to **QNX SDP 8.0**. Here, you will find a collection of easy-to-use C/C++ libraries for popular electronic components (Sensors, Motors, RFID, etc.), allowing you to focus on learning RTOS concepts rather than struggling with low-level hardware registers.

## 🧰 Supported Components (Libraries)

Currently, the repository includes (or is actively developing) libraries for the following modules:

*   ⚙️ **Servo Motors** - Easy angle and PWM control (Similar to Arduino's `Servo.h`)
*   🧭 **MPU6050** - 6-axis Accelerometer & Gyroscope sensor library
*   💳 **RFID** - Reading and writing tags seamlessly
*   *...and many more to come!*

## 🛠️ Getting Started

### Prerequisites
To use these libraries, you will need:
*   **QNX Software Development Platform (SDP) 8.0**
*   A cross-compilation toolchain setup for your target board.

### ⚠️ Important Note on Hardware Compatibility
> **Note:** All the libraries in this repository have been exclusively designed, built, and **tested on the Raspberry Pi 4**. While they may work on other QNX-supported boards with minor modifications, the pin mappings and I2C/SPI interfaces are optimized for the Pi 4.
